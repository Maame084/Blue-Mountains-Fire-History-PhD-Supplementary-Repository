# Climate Attribution Supplementary Data

This folder contains the climate, fire-weather, hydroclimate, climate-mode and population datasets used to support the thesis attribution analyses for the Upper Blue Mountains THPSS fire-history records.

The datasets support comparisons between charcoal accumulation, Raman-derived thermal maturity, rainfall-derived dryness, vapour pressure deficit, FFDI, climate modes and Blue Mountains population change.

## Folder structure

| Folder | Contents |
|---|---|
| 00_Index | File index and data dictionary workbook |
| 01_Rainfall_Dryness | Annual rainfall-derived dryness data |
| 02_Vapour_Pressure_Deficit | ERA5-derived VPD datasets and annual summaries |
| 03_FFDI | Annual Forest Fire Danger Index data |
| 04_Climate_Modes | Niño 3.4, SOI and DMI/IPO climate-mode files |
| 05_Population | Blue Mountains LGA population data |
| 06_Integrated_Datasets | Combined annual datasets for attribution panels |
| 07_Figures | Place attribution figures here |
| 08_Scripts | Place R/Python processing and plotting scripts here |
| 09_Metadata | Data dictionary and processing notes |
