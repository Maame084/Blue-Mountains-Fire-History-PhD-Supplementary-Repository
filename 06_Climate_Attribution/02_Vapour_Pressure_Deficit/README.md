# Vapour Pressure Deficit Data

This folder contains VPD datasets used as an indicator of atmospheric moisture demand and fire-weather stress in the Upper Blue Mountains attribution analyses.

## Files

| File | Description |
|---|---|
| 01_Katoomba_Area_Observation_Level_VPD_1940_2022.csv | Observation-level area-mean VPD values. |
| 02_Katoomba_Gridpoint_Daily_Maximum_VPD_1940_2022.csv | Daily maximum VPD from sampled gridpoints around Katoomba. |
| 03_Katoomba_Area_Daily_Maximum_VPD_Smoothed_1940_2022.csv | Daily area maximum VPD with 365-day and 1825-day centred smooths. |
| 04_Annual_VPD_Summary_1940_2022.csv | Annual summaries derived from the smoothed daily VPD dataset. |
