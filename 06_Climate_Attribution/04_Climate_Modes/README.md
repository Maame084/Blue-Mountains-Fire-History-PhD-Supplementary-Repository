# Climate Modes

This folder contains cleaned climate-mode datasets for thesis attribution analyses. Monthly files preserve the original temporal resolution; annual files provide calendar-year means for comparison with CHAR, Raman and annual hydroclimate records.

## Files

| File | Description |
|---|---|
| 01_Nino34_Monthly_SST_Anomaly_1870_2025.csv | Monthly Niño 3.4 SST anomaly. |
| 01a_Nino34_Annual_Mean_1870_2025.csv | Annual mean Niño 3.4 SST anomaly. |
| 02_Southern_Oscillation_Index_Monthly_1866_2025.csv | Monthly SOI. |
| 02a_Southern_Oscillation_Index_Annual_Mean_1866_2025.csv | Annual mean SOI. |
| 03_DMI_IPO_Monthly_Index_Cleaned_1950_2026.csv | Monthly DMI/IPO values as provided in uploaded workbook. |
| 03a_DMI_IPO_Annual_Mean_Index_1950_2026.csv | Annual mean DMI/IPO values. |
| 04_Climate_Modes_Annual_Combined_1900_2022.csv | Annual combined climate-mode table. |

[VERIFY] The uploaded DMI_IPO workbook did not distinguish DMI and IPO as separate sheets. Confirm source identity before thesis citation.
