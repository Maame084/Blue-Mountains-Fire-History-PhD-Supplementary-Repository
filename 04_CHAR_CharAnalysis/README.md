# CHAR and CharAnalysis outputs

This folder contains the supplied CharAnalysis outputs and one extraction script.

| File | Contents and status |
|---|---|
| `D1_CharAnalysis_Modern1900_Outputs.xlsx` | Time series, significant years, collapsed fire episodes, site summaries and fire-return-interval summaries for the modern-period analysis. |
| `04_extract_CharAnalysis_outputs.R` | R script used to extract or reorganise supplied CharAnalysis outputs. Review the script header and working-directory assumptions before reuse. |

The folder does not contain the complete end-to-end charcoal transformation, interpolation, composite and figure-generation workflow. ImageJ-derived inputs are archived in `../03_ImageJ_Charcoal_Analysis/`. Complete methods and interpretation are provided in the thesis.
