# Chronology data

This folder contains the chronology files supplied with the supplementary repository.

| File | Description |
|---|---|
| `Supplementary_Data_S1_OxCal_scripts.oxcal` | OxCal script file used for Bayesian chronology modelling. |
| `Supplementary_Data_S1_OxCal_scripts.txt` | Plain-text copy of the OxCal scripts for accessibility and review. |
| `Supplementary_Data_S2_Full_age_depth_outputs.xlsx` | Exported age–depth model outputs and associated chronology tables. |

These files support the temporal framework used for charcoal, Raman, loss-on-ignition, magnetic susceptibility, and ITRAX XRF analyses. Complete chronology methods and model interpretation are provided in the thesis.
