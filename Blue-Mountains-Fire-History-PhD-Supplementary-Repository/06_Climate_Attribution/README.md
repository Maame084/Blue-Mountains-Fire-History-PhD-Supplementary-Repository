# Climate-attribution supplementary data

This folder contains the hydroclimate, fire-weather, climate-mode, population and integrated datasets supplied for the thesis attribution analyses.

## Folder structure

| Folder | Contents |
|---|---|
| `00_Index/` | File index workbook and CSV. |
| `01_Rainfall_Dryness/` | Annual rainfall-derived dryness data. |
| `02_Vapour_Pressure_Deficit/` | Observation-level, daily, smoothed and annual VPD datasets. |
| `03_FFDI/` | Annual Forest Fire Danger Index data. |
| `04_Climate_Modes/` | Niño 3.4, SOI and the climate-index series analysed under the label DMI. |
| `05_Population/` | Blue Mountains LGA population data. |
| `06_Integrated_Datasets/` | Combined annual datasets used for attribution comparisons. |
| `07_Figures/` | Compiled attribution figures in raw units. |
| `09_Metadata/` | Data dictionary and processing notes. |
