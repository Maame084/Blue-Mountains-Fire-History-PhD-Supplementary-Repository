# Climate modes

This folder contains climate-mode datasets used in the thesis attribution analyses. Monthly files preserve the supplied temporal resolution, and annual files provide calendar-year means for comparison with CHAR, Raman and annual hydroclimate records.

| File | Description |
|---|---|
| `01_Nino34_Monthly_SST_Anomaly_1870_2025.csv` | Monthly Niño 3.4 SST anomaly. |
| `01a_Nino34_Annual_Mean_1870_2025.csv` | Annual mean Niño 3.4 SST anomaly. |
| `02_Southern_Oscillation_Index_Monthly_1866_2025.csv` | Monthly Southern Oscillation Index. |
| `02a_Southern_Oscillation_Index_Annual_Mean_1866_2025.csv` | Annual mean Southern Oscillation Index. |
| `03_DMI_Labelled_Monthly_Index_1950_2026.csv` | Monthly values of the climate-index series analysed under the label DMI. The original provider metadata could not be independently verified during final archiving. Values are preserved exactly as analysed. |
| `03a_DMI_Labelled_Annual_Mean_Index_1950_2026.csv` | Calendar-year means of the same DMI-labelled series. |
| `04_Climate_Modes_Annual_Combined_1900_2022.csv` | Combined annual climate-mode table used for alignment and comparison. |

The DMI-labelled files should not be represented as a newly downloaded or independently validated official DMI/IOD product.
