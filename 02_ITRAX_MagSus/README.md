# ITRAX XRF and magnetic susceptibility data

This folder contains the two workbooks supplied as Supplementary Data S3 and S4.

| File | Contents |
|---|---|
| `Supplementary_Data_S3_Original_ITRAX_MagSus_All_Sites.xlsx` | README and QA sheets, data dictionary, pooled data and site-level ITRAX XRF and magnetic-susceptibility tables for the analysed mire records. |
| `Supplementary_Data_S4_ITRAX_PCA_outputs.xlsx` | PCA variance, loadings, scores, data dictionary and summary outputs. |

These workbooks support the sediment-context and geochemical analyses described in Chapters 4–6 and Appendix C. The thesis is the authoritative source for methods and interpretation.
