# Blue-Mountains-Fire-History-PhD-Supplementary-Repository
10.5281/zenodo.21446388


## Repository Overview

This repository accompanies the PhD thesis:

**Fire Regime Shifts in the Twentieth Century in the Upper Blue Mountains, eastern Australia: Insights from Charcoal Records of Temperate Highland Peat Swamps on Sandstone (THPSS)**

**Author:** Maame Adwoa Maisie

**Institution:** University of Wollongong

This repository provides the complete reproducible research archive supporting the thesis. It contains the processed datasets, analytical workflows, statistical outputs, supplementary figures, scripts and documentation used to reconstruct Twentieth Century fire-regime variability in the Upper Blue Mountains, New South Wales, Australia.

The repository complements the thesis by providing materials that are too extensive for inclusion in the appendices while maintaining complete transparency and reproducibility.

---

# Research Objectives

The thesis aimed to:

- reconstruct Twentieth Century fire activity using sedimentary charcoal records from multiple THPSS sites;
- investigate changes in combustion conditions using Raman spectroscopy;
- establish robust Bayesian chronologies for peat records;
- characterise sediment composition using LOI, magnetic susceptibility and ITRAX XRF;
- identify relationships between fire activity, combustion conditions, hydroclimate, fire weather, climate variability and human population growth.
