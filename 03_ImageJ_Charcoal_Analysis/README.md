# ImageJ and raw charcoal quantification data

This folder contains ImageJ-derived charcoal particle counts and area measurements used as inputs to later charcoal accumulation and CharAnalysis workflows.

| File or folder | Description |
|---|---|
| `Supplementary_Data_S5_ImageJ_Charcoal_Count_Area.xlsx` | Supplementary workbook containing ImageJ-derived charcoal count and area data. |
| `Raw_Quantification/` | Additional raw charcoal quantification workbook and documentation. |

These data precede interpolation, CHAR calculations, transformations, and peak-detection analyses reported elsewhere in the repository and thesis.
